# cumba-oss-datasetjson

Dataset-JSON (DSJ) DTO model — Jackson beans for CDISC Dataset-JSON
v1.x files. Standalone module; used by
`cumba-oss-datatable-provider-dsj` as its parsed-model layer.

## Maven coordinates

```xml
<dependency>
    <groupId>net.cumba</groupId>
    <artifactId>cumba-oss-datasetjson</artifactId>
    <version>${revision}</version>
</dependency>
```

## Java packages

- `net.cumba.datasetjson.*`

## Dependencies

None on other Cumba OSS modules — pure Jackson DTO module.
